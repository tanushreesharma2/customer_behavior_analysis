# customer_behavior_analysis
Created an interactive Power BI dashboard to examine customer behaviors in e-commerce by utilizing techniques such as data cleaning, data transformation, and data visualization. Conducted analysis based on factors such as demographics, subscriptions, product categories, and shipping methods to generate actionable insights.
📊 Data Analytics Project

📌 Overview

This project demonstrates an end-to-end data analytics workflow, starting from data loading and exploration to visualization and reporting. It showcases skills in Python, SQL, and Power BI to derive actionable insights and present them effectively.

---

📂 Dataset

The dataset contains structured data related to customer behavior, transactions, and preferences. It includes attributes such as demographics, product categories, and purchase details used for analysis and visualization.

---

🛠️ Tools & Technologies

- Python (Pandas, NumPy, Matplotlib, Seaborn)
- SQL (PostgreSQL / MySQL / SQL Server)
- Power BI
- Gamma (for presentation)

---

🔄 Project Steps

1. Data Loading

- Imported dataset using Python
- Performed initial inspection of data structure and types

2. Exploratory Data Analysis (EDA)

- Analyzed distributions and relationships
- Identified trends, patterns, and anomalies

3. Data Cleaning

- Handled missing values
- Removed duplicates
- Standardized and formatted data

4. SQL Analysis

- Loaded cleaned data into relational databases
- Executed SQL queries to extract insights
- Performed aggregations and filtering

5. Dashboard Creation

- Built an interactive Power BI dashboard
- Visualized key metrics and trends
- Enabled filtering for dynamic analysis

6. Reporting & Presentation

- Created a detailed report summarizing findings
- Designed a presentation using Gamma

---

📊 Dashboard

The Power BI dashboard provides:

- Customer behavior analysis
- Category-wise performance insights
- Interactive filters for deeper exploration
- Clear visual representation of key metrics

---

📈 Results

- Identified important trends in customer behavior
- Highlighted top-performing categories
- Derived insights to support data-driven decision-making

▶️ How to Run

1. Clone the repository

3. Execute SQL queries in your preferred database system
